# App Icon Source Layers

These are 1024x1024 source assets for Apple Icon Composer.

- `TechBrosBudget.icon`: native Icon Composer document with the two image layers embedded.
- `AppIcon-Background.png`: opaque background layer.
- `AppIcon-Foreground.png`: transparent foreground layer with the character and TECH BROS wordmark.
- `AppIcon-Composite.png`: full-color flattened preview used for the light app icon.
- `AppIcon-QA.png`: local QA contact sheet, not an app asset.

The shipping app icon files live in `techbrosbudget/Assets.xcassets/AppIcon.appiconset`.
